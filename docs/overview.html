      BEFORE YOU BEGIN
      The questions worth asking.
      Clear expectations make a better first session—and a better presentation.
      Is the built-in demo an AI model?
      No. It is a labelled template-based route for trying the workflow. Connect a working local or hosted model for generated stories.
      Will restoring a checkpoint lose the earlier branch?
      Named checkpoints retain their saved timeline so you can return to that point and explore alternatives.
      Which interface should I choose?
      Start with the browser app. Gradio is an alternative browser client; Telegram requires its own package, token and explicit launch.
      I see the built-in demo instead of generated storytelling. Why?
      Check the selected provider and model service. An unavailable provider can use the labelled template demo. Hosted generation requires its explicit selection, credentials and offline mode disabled; Telegram has separate optional setup.
